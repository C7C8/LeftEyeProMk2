# Configs

This folder contains content configurations, web API configurations, and so on that are intended to be easily modified by a non-technical editor.
These files are in YAML format because it is cleaner and easier understood by non-technical users.

| File                | Purpose                                                                                    |
| ------------------- | :----------------------------------------------------------------------------------------- |
| `hero-images.yaml`  | "Hero" images to display on the front page.                                                |
| `publications.yaml` | Images that appear in the list of publications always present at the bottom of the screen. |
| `categories.yaml`   | Master hierarchical list of image categories and tags.                                     |
